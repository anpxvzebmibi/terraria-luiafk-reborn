## Overview

LuiAFK Reborn is an updated continuation of the classic LuiAFK mod, adding a suite of automation items — unlimited consumable versions of common potions, auto-buff accessories, infinite mining potion effects, passive health and mana regeneration items, and player stat buff items — that reduce repetitive buffing and crafting tasks during endgame Terraria play.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Terraria LuiAFK Reborn** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Unlimited Potions** | Craftable infinite-use versions of all common buff consumable potions |
| **Auto-Buff** | Accessories that automatically apply buff potions from inventory |
| **Infinite Mining** | Permanent mining speed, light, and obsidian skin effect items |
| **Endgame Items** | High-tier stat boost accessories for endgame farming and events |
